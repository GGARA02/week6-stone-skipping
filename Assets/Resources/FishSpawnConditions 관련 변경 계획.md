## fix/hs-p2 테스트 체크리스트

브랜치 자체 커밋(`ed0c734`, `fix: p2 고치는 중`)과 현재 미커밋 변경을 기준으로 작성했다. main 병합으로 들어온 변경은 제외했다. 아래 항목은 직접 플레이하며 확인할 내용이며, 이번 정리에서는 플레이 테스트를 실행하지 않았다.

### 1. 초기 상태와 도감

게임 데이터를 초기화한 뒤 확인한다.

| 테스트 | 기대 결과 |
|---|---|
| 첫 판 도감 열기 | 짱돌은 획득, 고등어·가자미는 발견 |
| 상시 발견 항목 확인 | 벽·화산·쇄빙선·블랙홀은 처음부터 이름과 힌트 표시 |
| 나머지 미발견 항목 확인 | 물음표 표시, 힌트 숨김 |
| 발견했지만 미획득인 항목 확인 | 이름·모델·힌트는 표시되지만 투척 선택 불가 |
| 물고기 획득 후 확인 | 즉시 획득 상태로 변경되고 설명·획득 수 표시, 투척 선택 가능 |
| 벽·유빙 힌트 확인 | 각각 `벽을 잘라내세요`, `유빙을 잘라내세요` |

### 2. 연결 해금과 출현 시점

| 테스트 | 기대 결과 |
|---|---|
| 고등어 획득 | 같은 판에서는 다음 항목이 해금되지 않고, 다음 판부터 날치·불가사리·뚝배기(`tire`) 해금 |
| 가자미 획득 | 다음 판부터 복어·찌그러진 캔·바게트 해금 |
| 불가사리 획득 | 다음 판부터 자동차·부캉이(`babyshark`) 해금 |
| 여러 단계를 건너뛰는지 확인 | 고등어만 먹었다고 불가사리 다음 단계까지 자동 해금되지 않음 |
| 플레이 모드 종료 후 재시작 | 획득 기록에 따른 해금 유지 |
| 부캉이 출현 확인 | 해금 후 정상 출현. 스폰 가중치는 0.025에서 0.1로 증가 |

가중치 `0.1`은 절대 출현 확률 10%라는 뜻은 아니다.
